# 2H4Y STL Studio 1.0
Offline Android-App. STL/OBJ/PLY/3MF importieren, Fotoausschnitt in druckbares 2.5D-Relief/Kontur umwandeln und STL exportieren.

Android Studio: Android-Projekt im Unterordner android öffnen, dann Build > Build APK(s).

Hinweis: Keine 360-Grad-KI-Rekonstruktion aus Einzelfotos.
